# 🐉 Dragon Sky Quest - Endless Flight & Trivia Adventure

A fast-paced, colorful, responsive 2D arcade browser game built with pure HTML5 Canvas, modern Glassmorphism CSS, and the Web Audio API.

---

## 🌟 Game Concept
**Dragon Sky Quest** combines the thrilling reflexes of an endless dragon-flying obstacle dodger with the intellectual excitement of general knowledge trivia gates:
$$\text{Fly} \longrightarrow \text{Dodge Crags} \longrightarrow \text{Collect Coins} \longrightarrow \text{Reach Milestone} \longrightarrow \text{Answer GK Quiz} \longrightarrow \text{Advance Biome} \longrightarrow \text{Repeat}$$

---

## 🎮 Controls

| Action | Keyboard | Mouse / Touch |
|---|---|---|
| **Flap Wings (Fly Up)** | `Space` / `W` / `↑` / `K` | Left Click / Canvas Tap / Mobile 🪽 Button |
| **Fast Dive** | `S` / `↓` | Hold `↓` |
| **Breathe Fireball** | `F` / `Shift` / `J` | Right Click / Mobile 🔥 Button |
| **Select Quiz Answers** | `1, 2, 3, 4` or `A, B, C, D` | Click / Tap Option Button |
| **Pause Game** | `P` or `Esc` | Click ⏸️ Button |

## ✨ Key Features

1. **Dynamic Procedural Dragon**:
   - Smooth flight physics with pitch tilt, dynamic wing flapping, and trail particles.
   - **Fire Breath System**: Shoot fireballs to blast through jagged sky crags!
   - **5 Elemental Dragon Skins**:
     - 🔴 *Crimson Blaze* (Fiery red scales & ember trail)
     - 🔵 *Sapphire Frost* (Ice cyan scales & frost sparkles)
     - 🟢 *Emerald Sprite* (Nature green scales & fairy dust)
     - 🟣 *Void Shadow* (Cosmic obsidian scales & void aura)
     - 🟡 *Celestial Gold* (Radiant gold scales & stardust)

2. **Milestone GK Quiz Gates**:
   - Ancient portals open every coin milestone (10, 12, 14... coins).
   - Over 100 curated questions across **Science & Tech**, **Space & Astronomy**, **World Geography**, **History**, **Nature & Animals**, and **Mythology**.
   - 15-second countdown timer.
   - Correct answers award streak score multipliers (up to 5x!), fire breath recharge, biome advancement, and reveal fascinating trivia facts.

3. **5 Evolving Parallax Biomes**:
   - 🌅 *Azure Meadows*: Clear morning skies and floating islands.
   - 🌇 *Sunset Horizon*: Radiant twilight mountains and amber lanterns.
   - ⚡ *Storm Peaks*: Dark thunderheads, rain streaks, and lightning flashes.
   - 🌌 *Mystic Aurora*: Cosmic purple night sky with undulating northern lights.
   - 🌋 *Magma Rift*: Fiery volcanic horizon with rising lava embers.

4. **Power-Ups & Collectibles**:
   - 🪙 **Golden Coins**: +10 pts, fills quiz portal progress.
   - 💎 **Celestial Gems**: Sapphire (+50 pts) and Diamond (+100 pts).
   - 🛡️ **Shield of Aethelgard**: Absorbs 1 rock collision.
   - 🧲 **Coin Magnet**: Gravitationally pulls all nearby coins and gems.
   - 🔥 **Fireblast Burst**: Rapid infinite fireball blast.
   - ⏳ **Time Warp**: Slows down sky obstacles for precision maneuvering.
   - ❤️ **Heart Potion**: Restores lost life (up to 3 hearts).

5. **100% Procedural Audio Engine (Zero Asset Dependencies)**:
   - Uses Web Audio API oscillator synthesis for wing flaps, coin jingles, gem harps, fire explosions, damage impacts, victory fanfares, and dynamic background arcade music.

6. **Persistent Leaderboards & Run Stats**:
   - High scores saved locally via `localStorage`.
   - Comprehensive post-flight summary: Distance, Coins, Trivia Accuracy %, Furthest Biome Reached, and Dragon Titles (*Apprentice Drake* to *Grand Celestial Wyrm*).

---

## 🚀 How to Run
Simply double-click `index.html` or open it in any modern web browser (Chrome, Edge, Firefox, Safari). No installation or web server required!
